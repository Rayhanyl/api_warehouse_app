# RULE_SYSTEM — Aturan Bisnis

Folder ini menjelaskan workflow dan aturan operasional yang berasal dari PRD.
Ia tidak membuat permission, status, kode error, atau requirement baru.

## Dokumen saat ini

| Dokumen | Fungsi |
| --- | --- |
| [REVIEW_PRD_DAN_ARSITEKTUR.md](REVIEW_PRD_DAN_ARSITEKTUR.md) | Audit, konflik, asumsi, dan rekomendasi; bukan spesifikasi yang disetujui |

Aturan bisnis yang mengikat saat ini berada di
[PRD_GENERAL.md](../core/PRD_GENERAL.md).
Saat aturan rinci baru ditambahkan, buat dokumen pemilik di folder ini dan
tautkan kembali ke ID PRD tanpa menyalin seluruh isi PRD.

## Batas status dokumen

Review, rekomendasi, dan pertanyaan terbuka harus diberi label jelas. Hanya
requirement yang disetujui pemilik proyek yang boleh digunakan sebagai dasar
perubahan kode atau test.
